## 3. 화면 상세

---

### SCR-01. 코드 발급 폼

**경로:** `/`
**설명:** 사용자가 이메일을 입력하고 코드를 요청하는 메인 화면

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│   라이브 참여 코드 발급               │  ← h1, 굵은 글씨
│   가입 시 사용한 이메일을 입력하시면   │  ← 설명 텍스트, 회색
│   코드를 발급해 드립니다.             │
│                                     │
│   이메일                             │  ← 라벨
│   ┌─────────────────────────────┐   │
│   │  example@email.com          │   │  ← 이메일 input
│   └─────────────────────────────┘   │
│                                     │
│   ┌─────────────────────────────┐   │
│   │       코드 발급받기           │   │  ← 파란색 버튼
│   └─────────────────────────────┘   │
│                                     │
└─────────────────────────────────────┘
```

**UI 요소 상세**

| 요소 | 타입 | 속성 |
|------|------|------|
| 제목 | `h1` | "라이브 참여 코드 발급" |
| 설명 | `p` | 회색, 소형 텍스트 |
| 이메일 입력 | `input[type=email]` | required, placeholder, 포커스 시 파란 테두리 |
| 발급 버튼 | `button[type=submit]` | 파란 배경, 로딩 중 비활성화 |

**상태별 화면 변화**

| 상태 | 변화 |
|------|------|
| 초기 | 폼 표시 |
| 로딩 | 버튼 텍스트 "확인 중…", 버튼 비활성화 |
| 에러 | 폼 아래 빨간 배경 에러 메시지 박스 노출 |
| 성공 | SCR-02로 인라인 전환 (페이지 이동 없음) |

---

### SCR-02. 발급 완료

**경로:** `/` (폼 영역을 결과 영역으로 교체)
**설명:** 코드 발급 성공 시 코드를 강조 노출

```
┌─────────────────────────────────────┐
│                                     │
│   라이브 참여 코드 발급               │
│   가입 시 사용한 이메일을 입력하시면   │
│   코드를 발급해 드립니다.             │
│                                     │
│   ┌─────────────────────────────┐   │
│   │  ✓ 코드가 발급되었습니다!    │   │  ← 초록 배경 박스
│   │                             │   │
│   │   LIVE-4KQMR7BN             │   │  ← 모노스페이스, 대형, 굵게
│   │                             │   │
│   └─────────────────────────────┘   │
│                                     │
│   이 코드를 안전한 곳에 저장해 두세요. │  ← 회색 안내 텍스트
│                                     │
└─────────────────────────────────────┘
```

**상태 분기**

| 케이스 | 상단 메시지 |
|--------|------------|
| 신규 발급 | "코드가 발급되었습니다!" |
| 기발급 재조회 | "이미 발급된 코드입니다." |

### SCR-03. 관리자 로그인

**경로:** `/admin`
**설명:** 관리자 인증 화면. 환경변수에 저장된 비밀번호와 대조

```
┌─────────────────────────────────────┐
│                                     │
│   관리자 로그인                       │
│                                     │
│   비밀번호                           │
│   ┌─────────────────────────────┐   │
│   │  ••••••••                   │   │
│   └─────────────────────────────┘   │
│                                     │
│   ┌─────────────────────────────┐   │
│   │           로그인              │   │
│   └─────────────────────────────┘   │
│                                     │
│   (오류 시) 비밀번호가 올바르지 않습니다│  ← 빨간 텍스트
│                                     │
└─────────────────────────────────────┘
```

**인증 방식**
- 입력한 비밀번호를 `/api/admin/auth` 로 POST
- 서버에서 `ADMIN_PASSWORD` 환경변수와 비교
- 일치 시 세션 쿠키 발급 → `/admin/dashboard` 리다이렉트

### SCR-04. 관리자 대시보드 — 세션 제어 탭

**경로:** `/admin/dashboard`
**설명:** 라이브 세션 ON/OFF 및 현황 파악

```
┌─────────────────────────────────────────────────┐
│  관리자 대시보드                      [로그아웃]  │
├─────────────────────────────────────────────────┤
│  [ 세션 제어 ]  |  발급 내역                      │  ← 탭
├─────────────────────────────────────────────────┤
│                                                 │
│  현재 상태                                       │
│  ┌──────────────────────────────────────────┐   │
│  │  🔴 라이브 OFF                            │   │  ← 상태 표시
│  │  시작: -         종료: -                  │   │
│  └──────────────────────────────────────────┘   │
│                                                 │
│  ┌───────────────┐                             │
│  │  라이브 시작   │  ← 초록 버튼 (OFF 상태 시)   │
│  └───────────────┘                             │
│                                                 │
│  최대 발급 수량                                  │
│  ┌──────────┐                                  │
│  │   500    │  명   [저장]                      │  ← 숫자 input
│  └──────────┘                                  │
│                                                 │
│  발급 현황                                       │
│  총 발급: 142건 / 500건                          │
│  ████████░░░░░░░░░░  28%                        │  ← 진행 바
│                                                 │
└─────────────────────────────────────────────────┘
```

**세션 상태별 버튼**

| 현재 상태 | 버튼 텍스트 | 버튼 색상 | 동작 |
|----------|------------|---------|------|
| OFF | "라이브 시작" | 초록 | isActive = true, startedAt 기록 |
| ON | "라이브 종료" | 빨간 | isActive = false, endedAt 기록 |

---

### SCR-05. 관리자 대시보드 — 발급 내역 탭

**경로:** `/admin/dashboard` (탭 전환)
**설명:** 발급된 코드 목록 조회 및 관리

```
┌─────────────────────────────────────────────────────────────┐
│  관리자 대시보드                                  [로그아웃]  │
├─────────────────────────────────────────────────────────────┤
│  세션 제어  |  [ 발급 내역 ]                                  │
├─────────────────────────────────────────────────────────────┤
│                                          [CSV 다운로드]      │
│                                          [전체 무효화]       │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  이메일              코드           발급 시각  상태  │   │
│  ├─────────────────────────────────────────────────────┤   │
│  │  user@ex.com   LIVE-4KQMR7BN   06-04 14:23  정상  │   │
│  │  other@ex.com  LIVE-9MZVQ3TF   06-04 14:25  정상  │   │
│  │  test@ex.com   LIVE-2BNJK8PX   06-04 14:26  무효  │   │
│  │  ...                                                │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**테이블 컬럼**

| 컬럼 | 내용 |
|------|------|
| 이메일 | 발급 요청자 이메일 |
| 코드 | 발급된 `LIVE-XXXXXXXX` 코드 |
| 발급 시각 | `MM-DD HH:mm` 형식 |
| 상태 | 정상 / 무효 / 사용됨 |
| 액션 | [무효화] 버튼 (정상 상태일 때만 표시) |

## 4. 에러 화면 처리

| 상황 | 처리 방식 |
|------|----------|
| 라이브 세션 비활성 | 폼 내 에러 메시지 인라인 노출 (별도 페이지 아님) |
| 미가입 이메일 | 폼 내 에러 메시지 인라인 노출 |
| 네트워크 오류 | 폼 내 에러 메시지 인라인 노출 |
| 관리자 인증 실패 | 로그인 폼 아래 에러 텍스트 노출 |
| 관리자 미인증 접근 | `/admin` 으로 리다이렉트 |
